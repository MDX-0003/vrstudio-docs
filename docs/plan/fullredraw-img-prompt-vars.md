# fullRedrawImg 提示词变量的按场景取值

状态：审查稿。`fullRedrawImg` 模板本身已在 vrgen 出厂；本文记录填写 `edit` / `preserve` 的规则与一个具体 case 的取值，以及为了让"只取光照"在模型侧成立所做的模板与角色文案调整。

## 1. 提示词存放位置

- 模板正文：`vrgen/templates/fullRedrawImg.md`，任何 case 都不得复制一份改写（决策 18：提示词不进 case，模板归 vrgen）。
- 变量取值：`vrgen_runs/<case 名>/prompt-vars.toml` 的 `[vars]`，键 `edit`（重绘内容）与 `preserve`（必须保持）；`canvas_w`、`band_w`、列号等几何键由 manifest 与提交清单自动展开，不写进草稿。
- 校验方式：`vrgen prompt show --job <case> --template fullRedrawImg --workdir <vrstudio>/vrgen_runs --image-role edit_master --image-role mask --canvas 9558x4096 --source 8192x4096`，`render_error` 必须为 null，正文里不得残留 `{…}` 占位符；web 生成页的提示词预览走同一条路径。

## 2. 填写规则

**`edit` 只写光，不写物体。** `fullRedrawImg` 的第一句就是整幅重绘，在 `edit` 里点名"烛台""落地灯""火盆"这类原图可能没有的物体，模型会把它们当成要新增的内容，随后与 `preserve` 的"不新增任何物体"打架；最终结果取决于模型偏向哪一边，不可控。

**唯一光源必须能对上原图里已有的实物。** 如果原图已有灯笼、灯架、窗洞，就把光源落在它们上面（"殿内立柱之间悬挂的宫灯""台阶下的地面灯笼"），这样"唯一光源"与"不新增光源"同时成立；原图没有的照明装置一律不写。写清没有其他光源（窗口、门洞、月光、顶光）能进一步压住模型补光。

**光影描述的顺序：光源与色温 → 衰减与层次 → 暗部 → 材质响应 → 空气 → 整体调色。** 每一项都写"变量"，不写"结果图长什么样"：明暗对比用"越远越暗、黑位扎实"，不用"把画面调暗"；倒影写"只保留灯笼附近的微弱暖光"，不用"加一层反光"。

**`preserve` 先列清单，再说只改什么。** 清单从图1 实际可见的元素里抄（人物数量位置姿态、服饰、道具、陈设、光源实物位置），最后一句限定"这些元素只改变受光、明暗与色调，形状、轮廓、数量与位置一律不动"，避免模型把"调整光影"理解成重排版面。

**氛围参考图必须是 `lighting_ref` 角色。** 决策 44 的根因就在这里：把氛围图标成 `scene_ref`，素材清单会授权模型继承构图与场景，返回画面会复刻参考图。`lighting_ref` 的固定文案（`IMAGE_ROLE_TEXT`）随即成为提示词里图3 的分工说明，所以它必须明确"不取场景与画面内容"（2026-10-30 已补），并且模板【禁止】里写明参考图内容不得进入结果。

## 3. 模板与角色文案的调整（vrgen）

- `IMAGE_ROLE_TEXT["lighting_ref"]` 改为"氛围与光影参考图（只读光线：光源位置、色温、明暗对比与空气质感；不取它的构图、背景、人物、场景与画面内容）"。
- `templates/fullRedrawImg.md`【禁止】末尾追加"不把参考图的画面内容带进来（氛围图只提供光线，它的场景、人物与陈设一律不得出现在结果里）"。
- `tests/test_image.py::test_image_roles_text_covers_lighting_ref` 同步断言新措辞。

## 4. case：relight_ref_gen_01

输入：`sources/360erp_test.png`（8192×4096 ERP），extract `20261030-171334`；`fullRedrawImg` 的 21:9 画布 9558×4096，冗余带 683、主内容 8192。

`vrgen_runs/relight_ref_gen_01/prompt-vars.toml`：

```toml
template = "fullRedrawImg"

[vars]
edit = "电影级低调布光：全场唯一光源是宫灯烛火，分布在两种摆位上——殿内立柱之间高处悬挂的宫灯，以及殿前台阶下低处的地面灯笼；两组光源一高一低、远近错落，没有窗口、门洞或月光等其他光源。色温统一在约 2000K 的低色温暖橙金光，光源本身最亮、饱和度最高，向外快速衰减。照明层次：宫灯周围的人物面部、衣料与灯笼纸面为高光区，明暗过渡柔和，阴影虚化；越往远处与高处越暗，殿顶梁架、柱身上段与庭院深处沉入接近全黑的暗部，黑位扎实、不发灰。地面石板只保留灯笼附近的微弱暖色倒影，不出现镜面反光。空气里有一层极淡的烟雾与浮尘，只在灯与灯之间、明暗交界处显出体积，不遮挡主体轮廓。所有光线都带着同一层暖色滤镜，暗部略偏红褐，整体是暖黄暗褐色调，高对比、低饱和。写实光影，电影质感。"

preserve = "严格保持图1的原始构图、镜头视角、空间结构、人物数量、人物位置、人物姿态、服饰造型、道具数量、灯笼与灯笼杆的位置、殿内陈设和整体画面边界；这些元素只改变受光、明暗与色调，形状、轮廓、数量与位置一律不动。不新增任何人物、物体、装饰、家具、建筑结构、光源或场景细节，不改变原图已有元素，不扩展背景，不补造不存在的细节。"
```

与最初提案的差别：原稿在 `edit` 里写的是"案几矮烛台与落地连枝灯纵向排列"，这两样是原图里没有的照明装置，等于要求模型新增物体，与 `preserve` 的禁令冲突；改为落在原图已有的宫灯与灯笼上。原稿 `preserve` 里的"烛台位置"同样改成了"灯笼与灯笼杆的位置"。

渲染结果（`prompt show`，`render_error` 为 null）：【参考图分工】当前只展开图1（基图）与图2（mask）；选中的氛围参考图会按上传顺序追加为图3，正文写入"图3 = 氛围与光影参考图（只读光线……不取它的构图、背景、人物、场景与画面内容）"。

## 5. 待确认

- 图3 只在案例里挂了 `lighting_ref` 素材、写进 `[submit] selected` 后才会出现；`relight_ref_gen_01` 当前的 `case.toml` 还没有 `[assets]` 与 `[submit]`，要按此案的实际氛围图补上。
- `[reference] 分工`之外，【全景约束】与【冗余带几何】提到的"图2 白色区域"是 mask 的白带；两者在渲染结果里是同一件事，不需要改写。
