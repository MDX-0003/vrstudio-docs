## 4. 页面与交互检查

已通过：

- 新建 case 抽屉、列表刷新、按流程进入向导。
- 提示词抽屉打开、变量编辑、400 毫秒自动保存；修改后刷新页面内容仍在，随后已还原。
- 任务中心“全部任务/我的任务”、任务详情、日志尾部、完整日志链接。
- 占用锁：第二个浏览器上下文提示 `case 正被 MDX 使用；保存仍会写入，请先沟通`。
- 非法步骤 URL `/not-a-step` 自动重定向到选区页。
- 1280 与 1920 宽度无横向溢出（1280 时 `scrollWidth=1270`）。
- 旧前端 `/case/qa_videoedit_1023` 仍可打开并显示任务记录。
- 重复上传同一文件返回 409；删除临时素材成功；编辑母版下移被后端拒绝并回滚。

发现的问题：

1. **上传进度不刷新**：上传网络请求已完成，但行一直显示 0%。原因是 `AssetUploadDialog` 把普通对象放进响应式数组后继续修改原对象，Vue 追踪不到。改为 `reactive<Row>` 后验证正常。提交 `c48030d`。
2. **首尾帧分辨率选项错误**：页面发送 480p/720p/1080p，vrgen 只接受 1K/2K/4K。改为 1K/2K/4K，默认 2K。提交 `c48030d`。
3. **自动尾帧档位不一致**：首帧 2K 时自动尾帧默认 4K，挑选时报“首帧与尾帧宽高不一致”。后端改为继承首帧宽度对应档位；本次测试因服务未重启，使用手动 2K 尾帧完成，新增单测 `test_keyframe_resolution_follows_first_asset_width`。提交 `c48030d`、`8ccac10`。
4. **采用后最近成片文案**：patch 的采用结果在 `extracts/<version>/result.mp4`，合并前 `outputs` 为空，页面原写“当前成片已是采用结果”。改为“已采用最新轮次，合并后在这里看成片”，空态改为“还没有合并成片”。提交 `8607d51`。
5. **母版下移按钮**：允许点击，但后端因“edit_master 必须第一条视频”返回 400，前端回滚。已禁用 `edit_master` 的下移按钮。提交 `8607d51`。
