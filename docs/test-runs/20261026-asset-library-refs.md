## 4. 与方案稿的差异

- 生成页的「去素材库管理」文字链接没有保留；case 顶栏的「素材库」开关是入口，避免在生成页重复放导航。
- 上传对话框不再让用户选库角色，按文件类型写默认角色（图片 `subject_ref`、视频 `motion_ref`）；实际角色在引用清单里设置，符合「素材库只存文件」。
- 视频选择器保留 clip/pad 流程产物（它们是视频提交候选）；素材库页只列 `[[assets]]` 文件。
- 角色说明用 `el-option` 的 `span title` 与关闭状态 `el-select` 的 `title` 实现；桌面悬停可见，移动端没有 hover。
- 首尾帧的锁定主图放在共享引用行里，带「主三视图」说明；首帧定稿锚点也作为锁定行显示，编号固定为图3，细节图从图4 起。
