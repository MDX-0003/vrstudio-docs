# VideoEdit 动作锁定问题与解决路线（审查稿）

本文整理 `simple_gen_01` 成片与原片的对照结果、Seedance 2.5 `videoEdit` 暴露出的能力边界，以及可行的解决路线。文末列出需要用户拍板的问题。状态：模板与实验 case 已准备，尚未提交生成，等待审查。

## 1. 结论

这次成片不符合预期的核心原因不是提示词措辞，而是模式选择：`videoEdit` 把输入视频当作动作与时间轴母版，只替换画面内容。白膜人物的动作、姿势、节奏和移动路径被原样继承，写实外观只是覆盖在这套动作上。因此“动作流畅、符合人体结构和物理”这个目标，在当前模式下无法通过提示词实现。

本次提示词还主动要求“动作起止时间、方向、幅度不变，不得插入新动作”，只允许关节自然弯曲。即使模型有重新编排动作的空间，提示词也把它关掉了。

## 2. 素材与成片事实

- 源视频：`sources/Simple_Anima_Test.mp4`，1920×1052，30fps，367 帧，12.23 秒。
- 成片：`cases/simple_gen_01/result.mp4`，1944×1066，24fps，289 帧，12.04 秒，通用闸门判定为 `ok`。
- 生成参数：Seedance 2.5，`videoEdit`，1080p 档，13 秒，`aspect_ratio=auto`，项目会话 `2060150528006080`。
- 平台把 30fps 输入重采样为 24fps，总时长从 12.23 秒变为 12.04 秒；动作顺序没有改变。

## 3. 观察证据

把原片与成片按同一时间点抽帧对照，取样点为 0、2、4、6、8、10 秒：

- 0 秒：原片白膜坐在案几后、双臂向两侧张开；成片里的黑红服饰人物在同一位置、同一姿势坐着，双臂同样张开。
- 2 秒：两边都保持张臂，身体开始离座；姿势与节奏对应。
- 4 秒：两边都处于站直过程中的同一阶段，手臂角度一致。
- 6 秒：原片白膜向画面左侧移动；成片人物在同一时间向同一方向移动，步态与位置对应。
- 8 秒、10 秒：两边都保持站立，位置与朝向对应。

视觉检查还确认：宫殿背景、其他坐着的人物、右侧黑袍人物、顶部编辑器工具栏和右下角界面文字基本保持原样。也就是说，外观替换与背景保留是成功的，失败的是动作质量。

## 4. VideoEdit 的能力边界

### 4.1 它设计用来做什么

`videoEdit` 是结构锁定式编辑：输入视频占据输出的时间轴与构图，模型在保持原动作、原运镜的前提下修改画面内容。官方 BytePlus 的 Seedance 2.0 提示词指南写明，视频编辑时输入视频控制“原始的全部动作与运镜”；本项目 2026-10-19 的实测结果与该描述一致。2.5 的完整结构锁定参数尚未取得一手文档，标记为待验证，但实测已足以说明动作不会被重新编排。

### 4.2 本次暴露的具体缺陷

1. **动作不可重演**：白膜的僵硬起身、关节角度和重心转移被完整继承，写实人物只是“穿着新皮肤做同一套动作”。
2. **动作与背景耦合**：`videoEdit` 能很好地保留背景，但代价是同时锁死动作。无法在同一模式下只放开动作、保留背景。
3. **时间轴被重采样**：输入 30fps 被压到 24fps，时长从 12.23 秒变为 12.04 秒。动作顺序不变，但“逐帧时间完全一致”并不成立。
4. **身份只靠文本**：本次没有角色参考图，写实人物的脸、发型、服装只能由文字约束，容易出现“大致是古代人物，但不是指定人物”的漂移。参考图能改善身份，但不能解锁动作。
5. **编辑器界面被当作画面内容保留**：顶部工具栏与右下角控件原样留在成片里。这对“其他区域不变”是符合预期的，但如果目标是干净画面，需要额外的裁切或合成。

### 4.3 提示词层面的问题

本次提示词的关键段落是：

- 固定约束第 4 条：“时间轴与输入一致：每个动作的起止时间、方向、幅度不变；不得插入新动作或改变原有顺序。”
- 允许变化：“只允许白色白膜人形被替换成上述写实人物；允许皮肤、头发、服装材质和光影随之变化；允许手臂与腿部在起身过程中按人体关节自然弯曲、重心平滑转移；不允许改变动作起止时间、位置、朝向和行走路线。”

这两段把目标限定为“外观替换 + 局部关节微调”，与用户期望的“重新生成自然动作”不是同一件事。提示词没有写错，它准确执行了模式允许的范围；问题在于我们要求的能力超出了这个范围。

## 5. 可行路线

### 路线 A：先生成表演，再合成回原背景

做法：

1. 用允许重新生成动作的模式（例如 Seedance 2.5 `allMediaRef`，或角色参考图加文本分镜）生成一段写实人物的完整表演。
2. 生成时明确镜头固定、背景可以是生成结果，动作按整数秒分镜描述。
3. 用分割/抠像把人物从生成结果中取出，贴回原片的人物位置，保留原背景、原界面与原镜头。
4. 对齐人物的尺寸、脚部接触点、地面阴影与前后遮挡，再做融合。

优点：

- 背景可以保持原片，动作可以是新生成的，能同时满足“其他区域不变”和“动作自然”。
- 人物身份可以通过参考图稳定下来。
- 可以复用现有 patch/merge 的 mask 与融合能力。

代价：

- 这是一个新的“生成 + 合成”流程，不是现有 gen 流程加一个提示词就能完成。
- 人物与背景的接触、阴影、遮挡需要后处理；合成边缘可能暴露。
- 需要角色参考图，以及一个能生成新动作的模型模式。

### 路线 B：整镜头重新生成，接受背景变化

做法：

- 用 `allMediaRef` 或参考图模式，把原片当作场景/构图参考，把角色图当作身份参考，用文本分镜描述新的起身表演。
- 一次生成完整镜头，不做事后合成。

优点：

- 流程最短，最有机会得到自然的人体动作。
- 身份与动作都由提示词和参考图控制，迭代成本低。

代价：

- 背景、其他人物、编辑器界面都可能被重画，无法保证逐像素不变。
- 如果“其他区域不变”是硬要求，这条路线不满足。

## 6. 路线对比与建议

- 如果“其他区域不变”是硬要求：选路线 A。它是唯一能同时保留原背景与生成新动作的路线，但需要新增合成流程。
- 如果“动作自然”优先、背景可以变化：选路线 B。它最可能快速看到自然表演，再决定是否为了背景回到路线 A。

在决定投入 A 或 B 之前，先用 VideoEdit 做一次“最大努力提示词”的边界实验：如果连放开关节姿态、明确要求重演动作都仍然逐帧复刻白膜，就可以确认 VideoEdit 的能力上限，后续不再在提示词上投入；如果动作有明显改善，则先评估它是否已经够用，再决定是否需要 A/B。

## 6.1 本轮实验：VideoEdit 最大努力提示词

实验 case：`simple_gen_VideoEdit`，与 `simple_gen_01` 使用同一源视频，flow 为 gen，项目会话为“cli会话_测试”。

提示词策略：

- 锁定动作语义：顺序、起止时间、行进方向、画面位置不变。
- 放开关节姿态：允许在同一时间窗内重新设计关节角度、重心路径与身体姿态。
- 明确不复刻白膜的具体骨骼角度，只沿用动作语义与节拍。
- 把人体结构写成可执行条件：脚掌着地、膝盖约 90 度、重心从臀部移到双脚、衣摆滞后。
- 身份仍由文本约束；本轮没有角色参考图。

这是 VideoEdit 模式下最有可能改善动作的写法。它是否有效取决于模型把“结构锁定”理解到关节层还是语义层，本次实验的目的就是测出这条边界。

测试流程（尚未执行）：

1. 打开 `simple_gen_VideoEdit` 的生成页，确认模板正文包含【动作重演规则】，变量值已写入。
2. 确认输出分辨率 1080p、输入缩放 auto、项目会话为“cli会话_测试”。
3. 点击“提交生成”，等待约 3–4 分钟并采用结果。
4. 按 0、2、4、6、8、10 秒抽取原片与成片，对照姿势、关节角度、重心与移动路径。
5. 重点判断：动作是否仍然逐帧复刻白膜；关节是否更自然；脚是否滑动；背景与界面是否保持。
6. 如果动作仍然完全一致，记录为 VideoEdit 边界确认，转入路线 A 或 B；如果动作改善，评估是否达到可用标准。

## 7. 测试观察指标

- 动作是否重新编排：对照同一时间点的姿势，不再逐帧复刻白膜。
- 人体结构：关节角度、头身比、手脚数量与形状。
- 物理表现：脚掌接触、重心转移、衣料惯性、无穿模与漂浮。
- 背景保持：宫殿结构、其他人物、界面文字的变化范围。
- 身份一致：脸、发型、服装是否接近参考图。
- 时间契约：输出帧率、时长、动作起止时间。
